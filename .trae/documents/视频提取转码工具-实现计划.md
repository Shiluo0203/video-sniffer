# 视频提取与转码工具 — 实现计划

## Context

用户需要一个 Windows 桌面工具，解决三类问题：
1. **视频提取**：粘贴视频链接（含 Telegram 公开频道、常见视频站、m3u8/HLS 流及 AES-128 加密 HLS）→ 解析 → 选择清晰度 → 下载。
2. **视频转译**：本地视频（mkv/avi/mov/webm/flv/ts 等）→ mp4（H.264/AAC）；m3u8（URL 或本地文件，支持自定义请求头防盗链）→ 合并为单个 mp4。
3. **简单剪辑**：多视频合并为一个；按起止时间剪切片段（快速无损/精确重编码两种模式）。

已与用户确认的边界：

* 形态：**桌面 GUI**（PySide6，可 PyInstaller 打包 exe）

* Telegram 场景：**公开频道/群组链接**（t.me/...，yt-dlp 直接支持，无需登录）

* **不做 DRM**（Widevine/FairPlay 等商业加密）；HLS AES-128（key 可公开获取）正常支持

## 环境现状

* 工作目录 `e:\Tools\视频整合解析析取` 为空（全新项目）

* Python 3.14.7 已装；ffmpeg、yt-dlp 未安装

* PySide6 6.10+ 官方支持 Python 3.14（固定 `>=6.10,<6.12`），可用

## 技术栈

| 层    | 选型                                    | 职责                                             |
| ---- | ------------------------------------- | ---------------------------------------------- |
| GUI  | PySide6                               | 三标签页主窗口（下载 / 转码 / M3U8），QThread + Signal 防界面冻结 |
| 解析下载 | yt-dlp（Python API `yt_dlp.YoutubeDL`） | 链接解析、格式列表、下载、m3u8/AES-128 自动合并解密               |
| 转码合并 | ffmpeg（子进程调用）                         | 本地文件转 mp4、m3u8 拉流合并                            |

```
│   ├── m3u8_service.py        # m3u8 参数组装（URL/本地文件、自定义 headers）→ 调 ffmpeg_service

│   ├── main_window.py         # 主窗口 + QTabWidget（5 个标签页）+ 设置区（ffmpeg 状态、yt-dlp 更新按钮、Cookie 配置）
│   ├── workers.py             # QThread 工作线程基类，统一 Signal 协议(progress/log/finished/error)
│   ├── tab_download.py        # 链接输入(支持批量) → 解析 → 格式表格 → 下载队列 + 进度条 + 取消
│   ├── tab_transcode.py       # 本地文件列表(拖放/浏览) → CRF/分辨率选项 → 批量转码
│   ├── tab_m3u8.py            # m3u8 URL/本地文件 + Referer/UA/Cookie 输入 → 合并输出 mp4
│   ├── tab_merge.py           # 合并页：文件列表(添加/删除/上下移动排序) → 快速或重编码模式 → 输出单个文件
│   └── tab_cut.py             # 剪切页：选文件(显示时长) → 起止时间 → 快速无损(-c copy)/精确(重编码) → 输出片段
└── bin/                       # 运行时自动放置 ffmpeg.exe
```

## 关键设计

* **线程模型**：所有解析/下载/转码在 QThread 中执行，工作线程只发 Signal，主线程槽函数更新 UI；任务执行期间禁用对应操作按钮，支持取消。

* **yt-dlp 下载**：`extract_info(url, download=False)` 取元数据；用户选格式后以 `format` 选择器 + `progress_hooks` 下载。HLS（含 AES-128）由 yt-dlp 自动分片下载、解密、合并。

* **ffmpeg 进度**：`subprocess.Popen([...], stdout=PIPE)` + `-progress pipe:1`，解析 `out_time_ms` / 总时长算百分比；参数用列表传递（不用 shell=True），规避中文路径问题。

* **m3u8 合并**：`ffmpeg -headers "Referer: ...\r\nUser-Agent: ...\r\nCookie: ...\r\n" -i <url> -c copy -bsf:a aac_adtstoasc out.mp4`；AES-128 key 若可公开访问由 ffmpeg 自动解密。

* **视频合并**：生成临时 concat 列表文件（`file 'path'` 每行一条）。同编码快速模式：`ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4`（无损秒完成）；勾选"重编码兼容模式"则 `-c:v libx264 -c:a aac` 统一输出，兼容不同编码/分辨率的文件。

* **视频剪切**：快速模式 `ffmpeg -ss <start> -to <end> -i in.mp4 -c copy out.mp4`（无损但切点对齐关键帧，可能差几秒）；精确模式同样参数但重编码（libx264/aac），切点精确到帧。时长用 `ffprobe -show_entries format=duration` 获取显示。

* **ffmpeg 获取**：`shutil.which` → `bin/ffmpeg.exe` → 都没有则在设置区提示一键下载 gyan.dev `ffmpeg-release-essentials.zip` 解压。

* **yt-dlp 维护**：设置区提供"更新 yt-dlp"按钮（`python -m pip install -U yt-dlp`），应对站点规则变化。

## 实现步骤

1. 初始化项目：`requirements.txt`（PySide6、yt-dlp、requests）、安装依赖、`core/ffmpeg_locator.py` + ffmpeg 自动下载
2. `core/ffmpeg_service.py`（转码 + 进度 + 取消）→ `core/m3u8_service.py` + `core/video_edit_service.py`（合并/剪切）
3. `core/ytdlp_service.py`（解析 + 格式列表 + 下载）
4. `ui/workers.py` 线程框架 → `ui/main_window.py` + 五个标签页
5. `main.py` 入口联调
6. 端到端验证（见下）；可选 PyInstaller 打包（onedir + `--collect-all yt_dlp` + 内置 bin/ffmpeg.exe）

## 验证

1. **转码**：将一个本地 mkv/flv 转为 mp4，进度条正常推进，输出可播放
2. **m3u8**：用公开测试 HLS 流（如 Apple bipbop 测试流）合并为 mp4；带 Referer 的场景验证 headers 生效
3. **链接下载**：用 Telegram 公开频道链接（t.me/s/...）及任一常见视频站链接解析出格式列表并下载，验证进度/取消
4. **批量**：多链接/多文件队列依次执行，取消单个任务不影响队列
5. **合并**：两个 mp4 合并为一个可播放文件（快速模式、重编码模式各验证一次）
6. **剪切**：截取一个 10 秒片段，快速模式与精确模式均验证输出可播放、时长正确
